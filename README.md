# SWYNEX - Data Cleaning & Preparation

## Project Overview

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies.

For this task, I worked with a public Online Retail dataset and used Microsoft Excel and Power Query for data cleaning and preparation.

## Dataset

**Source:** UCI Online Retail II dataset

**Working Dataset:** 10,000-row sample extracted from the original public dataset for data cleaning and preparation.

## Data Cleaning Performed

- Identified missing values
- Replaced missing values with `N/A`
- Removed duplicate records
- Corrected data types
- Corrected the Invoice column data type to Text
- Prepared the dataset for further analysis

## Results

- **Raw dataset:** 10,000 rows
- **Duplicate records removed:** 83
- **Final cleaned dataset:** 9,917 rows
- **Missing Description values handled:** 16
- **Missing Customer ID values handled:** 2,812

## Tools Used

- Microsoft Excel
- Power Query

## Key Learning

This task helped me understand the importance of data cleaning and preparation before performing further analysis. It also gave me practical experience in identifying data quality issues and preparing a structured dataset for analysis.
